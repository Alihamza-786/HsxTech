# Web design

Design your website using building blocks, customize its theme with various options, structure and present content with elements, and display or hide building blocks using visibility settings.

* Building blocks
Design your website by dragging and dropping building blocks, then editing them to fit your content and layout needs. 
* General theme
Customize your website’s theme by adjusting its colors, fonts, and layout. 
* Elements
Structure and present content effectively with elements such as titles, lists, etc. 
* Visibility
Display or hide building blocks based on several criteria.
