# Nuvei

Nuvei is a Canadian-based payment solution provider that covers several Latin American countries, the US, and Canada. It allows businesses to accept credit cards and several local payment methods.

## Configuration on the Nuvei Dashboard

  1. Create a Nuvei account, if necessary, via our referral page.

  2. Nuvei uses two separate portals for Sandbox and Production environments. Utilize the Sandbox Dashboard to test the integration without charging your customers. Once you are ready to accept payments, switch to the Production Dashboard.

  3. Go to Settings in the left sidebar, select My Integration Settings, then select your payment page in the Website dropdown menu.

  4. Copy the Merchant ID and Site ID values and save them for later.

  5. Click Reveal, then copy the Secret Key and save it for later.

Tip

Nuvei supports additional functionality relating to error handling from the same page as above. For example, the following options are available for handling failed transactions: Enable User Trap to redirect users back to the payment page and allow them to attempt another deposit or Decline Recovery to display a popup suggesting alternative or similar payment methods.

## Configuration on Odoo

  1. Navigate to the payment provider Nuvei and fill in the Merchant Identifier, Site Identifier, and Secret Key fields with the information saved at the step Configuration on the Nuvei Dashboard.

  2. To activate the provider, change its state to Enabled or Test Mode.

  3. Configure the rest of the options to your liking.

Tip

You can also test Nuvei using the test mode and your Sandbox Dashboard values.
