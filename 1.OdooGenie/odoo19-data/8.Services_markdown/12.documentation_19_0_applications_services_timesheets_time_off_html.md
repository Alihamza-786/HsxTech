# Create Timesheets upon Time Off Validation

Odoo automatically timesheets on project/tasks upon time off requests. This allows for better overall control over the validation of timesheets, as it does not leave place for forgetfulness and questions after hours that have not been timesheeted by the employee.

Activate the developer mode, go to _Timesheets_ , and change the _Project_ and _Task_ set by default, if you like.

Go to Time Off ‣ Configuration ‣ Time Off Types. Select or create the needed type, and decide if you would like the requests to be validated or not.

Now, once the employee has requested his time off and the request has been validated (or not, depending on the setting chosen), the time is automatically allocated on _Timesheets_ , under the respective project and task.
