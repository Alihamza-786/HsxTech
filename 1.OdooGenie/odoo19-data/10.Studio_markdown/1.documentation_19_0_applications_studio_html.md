# Studio

  * Views
  * Models, modules, and apps
  * Automation rules
    * Webhooks
  * PDF reports
  * Approval rules

**Studio** is a toolbox used to customize Odoo without coding knowledge. For example, in any app, add or modify:

  * Fields

  * Views

  * Models

  * Automation rules

  * Webhooks

  * PDF reports

  * Approval rules

  * Security rules

Learn how to build an app from scratch.

To access Studio, navigate to the app and model you want to modify, then click the __( Toggle Studio) icon, or vice versa.

To close **Studio** , click Close in the upper-right corner.
